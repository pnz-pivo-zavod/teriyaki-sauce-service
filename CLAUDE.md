# teriyaki-sauce-service

Бэкенд таск-трекера (Telegram miniapp) на Go.

## Текущая задача

Деплой на VPS: `.claude/tasks/deploy.md` — прочитай целиком перед любой работой.

## Сделано

API v1 по документации из Confluence (решения и история — `.claude/tasks/api-v1.md`, читать, если
меняешь API).

## Как работаем

- Делаем ровно один подпункт плана (например, 1.2) и останавливаемся для проверки.
- Ничего не коммитим — коммиты делает пользователь (Conventional Commits, хуки lefthook).
- После коммита пользователя отмечаем подпункт `[x]` и пишем строку в «Журнал» плана.
- Новые решения по ходу — сразу в раздел «Решения» плана.
- В Jira не ходим.
