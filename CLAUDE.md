# teriyaki-sauce-service

Бэкенд таск-трекера (Telegram miniapp) на Go.

## Текущая задача

API v1 по документации из Confluence. Контекст, решения, план и прогресс:
`.claude/tasks/api-v1.md` — прочитай целиком перед любой работой.

## Как работаем

- Делаем ровно один подпункт плана (например, 1.2) и останавливаемся для проверки.
- Ничего не коммитим — коммиты делает пользователь.
- После коммита пользователя отмечаем подпункт `[x]` и пишем строку в «Журнал» плана.
- Новые решения по ходу — сразу в раздел «Решения» плана.
- В Jira не ходим.
